# 업종 · 개인 목표별 출발점

Q4 · Q5 · Q6 · Q10 선택지를 만들 때 쓴다. 사용자 업종에 맞는 줄만 꺼낸다. 맞는 것이 없으면 가장 가까운 것 + 「공통」.
각 줄: 대상 예시(Q5) · 검색하는 말 예시(Q6) · 증거 예시(Q10) · 조심할 표현.
업종 묶음은 geo-text 의 industries.md 와 같은 9묶음이다.

## 공통
- 대상: 처음 알아보는 사람 / 비교하며 고르는 사람 / 다시 찾는 단골
- 검색하는 말: 「(하는 일) + (지역)」, 「(하는 일) + 추천」, 「(대상) + (하는 일)」
- 증거: 해 온 기간 · 횟수 / 직접 만든 자료 · 공개한 기준 / 후기
- 조심: rules.md 과장 낱말

## 브랜드 · 업종 9묶음

### 1. 교육 · 자격
- 대상: 처음 배우는 사람 / 자격 준비생 / 자녀 교육을 알아보는 부모
- 검색하는 말: ○○ 학원 · ○○ 과외 · ○○ 자격증 준비 · ○○ 인강
- 증거: 수업 기간 · 수강생 수 / 커리큘럼 공개 / 강사 자격
- 조심: 합격률 · 실적은 기준 연도와 함께, 「최다 · 1위」 금지

### 2. 생활용품 · 식품 (육아용품 · 반려동물 포함)
- 대상: 성분 · 재료를 꼼꼼히 보는 사람 / 처음 써 보는 사람 / 선물 찾는 사람
- 검색하는 말: ○○ 추천 · 수제 ○○ · 무첨가 ○○ · (대상) ○○
- 증거: 원재료표 · 성분표 공개 / 시험 · 인증 이름 / 판매 기간
- 조심: 일반 식품의 효능(면역 · 해독 · 혈당), 「완벽 제거」 같은 단정

### 3. 뷰티 · 패션
- 대상: 예민한 피부 / 사이즈 · 핏을 고민하는 사람 / 특정 상황용(결혼식 · 출근)
- 검색하는 말: ○○ 추천 · 민감성 ○○ · ○○ 고르는 법
- 증거: 성분 역할 설명 / 시험 · 인증 / 제작 과정 공개
- 조심: 기능성 범위를 넘는 효능, 기준 없는 「무첨가」

### 4. 가구 · 인테리어 · 시공
- 대상: 좁은 집 · 원룸 사는 사람 / 이사 · 신혼 준비 / 부분 수리 알아보는 사람
- 검색하는 말: 원목 가구 · 맞춤 가구 · ○○ 인테리어 · ○○ 시공 비용
- 증거: 시공 · 제작 사례 수 / 소재 · 치수 공개 / 해 온 기간
- 조심: 건강 효능(새집증후군), 비용은 범위 · 기준 시점과 함께

### 5. 가전 · IT · B2B (렌탈 포함)
- 대상: 도입을 검토하는 담당자 / 처음 써 보는 개인 / 계약 · 해지를 앞둔 사람
- 검색하는 말: ○○ 비교 · ○○ 도입 · ○○ 렌탈 · ○○ 가격
- 증거: 도입 사례 수(익명) / 사양 공개 / 운영 기간
- 조심: 「1위 · 최초」, 시험 조건 없는 수치

### 6. 여행 · 숙박 · 외식
- 대상: 가족 여행 / 외국인 여행자 / 단체 · 모임
- 검색하는 말: (지역) 맛집 · (지역) 숙소 · (지역) ○○ 체험
- 증거: 운영 기간 · 방문객 / 메뉴 · 요금 공개 / 위치 · 이동 시간
- 조심: 「최저가 · 추가 비용 없음」(별도 요금 있으면 틀린 말)

### 7. 의료 · 헬스 (규제)
- 대상: 처음 진료받는 사람 / 특정 증상으로 찾는 사람 / 외국인 환자
- 검색하는 말: (지역) ○○과 · ○○ 진료 · ○○ 상담
- 증거: 의료진 경력(사실만) / 진료 과목 · 장비 / 진료 시간 · 위치
- 조심: 치료 효과 · 비교 · 우월 표현 금지, 후기 · 전후 사진 제한. 리포트에 「광고 규정 확인」

### 8. 법률 · 금융 · 부동산 (규제)
- 대상: 처음 상담받는 개인 / 회사 담당자 / 계약을 앞둔 사람
- 검색하는 말: ○○ 상담 · ○○ 변호사 · ○○ 노무사 · ○○ 절차
- 증거: 자격 · 등록 / 다룬 분야 / 운영 기간
- 조심: 승소율 · 수익 보장 금지. 리포트에 「광고 규정 확인」

### 9. 마케팅 · 판촉 · 행사
- 대상: 행사를 맡은 담당자 / 작은 회사 대표 / 해외 기업
- 검색하는 말: ○○ 대행 · ○○ 기획 · ○○ 제작
- 증거: 진행 건수 · 사례 / 클라이언트 업종(이름은 동의 받은 것만)
- 조심: 「업계 1위 · 최다」

## 개인 목표 4

### 취업 · 이직
- 대상: 채용 담당자 / 같은 직무 사람 / 헤드헌터
- 검색하는 말: (직무) 포트폴리오 · (직무) (도구)
- 증거: 프로젝트 수 · 결과 숫자(공개 가능한 것) / 자격 · 수료
- 조심: 전 회사 내부 숫자 · 고객 이름

### 일 받기 (프리랜서 · 강사 · 코치)
- 대상: 일을 맡길 사람 · 기관 담당자 / 배우려는 사람
- 검색하는 말: (지역) (분야) 강사 · (분야) 외주 · (분야) 클래스
- 증거: 수업 · 작업 횟수 / 자격 / 공개한 작업물
- 조심: 「최고의 · 1등 강사」

### 내 글 · 작품 알리기
- 대상: 같은 주제를 좋아하는 사람 / 협업 제안자
- 검색하는 말: (주제) 기록 · (주제) 리뷰 · (주제) 영상
- 증거: 발행 수 · 구독자 / 대표 작품
- 조심: 남의 작품 · 사진 사용

### 창업 준비
- 대상: 첫 손님이 될 사람 / 투자 · 협업 상대
- 검색하는 말: (만들 것) + (지역) · (만들 것) 추천
- 증거: 준비 과정 기록 / 시제품 · 테스트 결과
- 조심: 아직 없는 실적을 있는 것처럼 쓰지 않기
