# 질문 대본 (Q1~Q16)

표기: **[칩]** 은 AskUserQuestion 의 짧은 머리표(12자 이내). 「직접 입력」은 도구가 자동으로 붙인다.

### 0 · 첫 인사 (매번, 그대로)
```
AI 가 나를 소개하는 한 줄을 만들어 볼게요. (15~20분)

손님이 ChatGPT 에 「OO 어디가 좋아?」라고 물으면,
AI 는 사이트와 SNS 에 적힌 소개를 모아서 답해요.
그 소개가 없거나 곳곳에서 다르면, AI 는 나를 모르거나 엉뚱하게 말해요.
그래서 AI 가 할 말을 내가 먼저 정해 두는 거예요.

이렇게 진행돼요
1. 객관식 질문 몇 개에 답해요 (누구에게 · 무엇을 · 해 온 일)
2. 「나를 한 줄로」 후보 3개 중에 골라요
3. 5주 동안 AI 에게 물어볼 질문 3개를 정해요
4. 그 한 줄로 사이트 · SNS 소개를 같은 말로 맞춰요
5. 리포트가 열려요 → 어디에 무엇을 붙일지 한눈에 봐요

없는 숫자나 경력은 만들지 않아요. 말해 주신 것만 써요.
```
`geo/concept.md` 가 이미 있으면 덧붙임: 「지난번에 정한 컨셉이 있어요. 점검부터 할게요.」 → Q3 을 묻지 않고 점검 모드로.

### 1단계 · 시작 (객관식 3개 한 번에)

**Q1 [누구]** 누구를 알리고 싶어요?
| 선택지 | 설명 |
|---|---|
| 나 (개인) | 예: 요가 강사, 데이터 분석가, 커리어 코치 준비생 |
| 브랜드 · 가게 · 회사 | 예: 반려견 수제 간식 공방, 1인 인테리어 스튜디오 |

**Q2 [사이트]** 사이트는 지금 어떤 상태예요?
| 선택지 | 설명 | 고르면 |
|---|---|---|
| 아직 없어요 | 이번에 새로 만들어요 | — |
| 만드는 중이에요 | 주소나 초안이 있어요 | 1-1 에서 주소 받기 |
| 운영 중이에요 | 열려 있고 직접 고칠 수 있어요 | 1-1 에서 주소 받기 |
| 회사 · 고객사 사이트예요 | 고치려면 승인이 필요해요 | 「직접 못 고치면 실험용 사이트를 따로 여는 방법도 있어요」 한 줄 |

**Q3 [지금 문구]** 지금 쓰는 소개 문구가 있어요? (SNS 소개, 사이트 첫 문장 등)
| 선택지 | 설명 | 모드 |
|---|---|---|
| 있어요 | 붙여 넣을게요 | 점검 |
| 있는데 마음에 안 들어요 | 다시 보고 싶어요 | 점검 |
| 없어요 | 처음부터 만들어요 | 새로 만들기 |

**1-1 · (점검 모드거나 사이트 주소가 있을 때) 채팅**
```
지금 쓰는 소개 문구를 붙여 넣어 주세요.
사이트 주소나 인스타 · 블로그 주소가 있으면 같이 주세요.

예) 몸과 마음이 편안해지는 요가 ✨ 최고의 힐링을 선물합니다
    https://mysite.com
```
- **사이트 읽어 오기**: 주소를 받으면 Claude 가 그 페이지를 직접 열어 지금 걸려 있는 ① 사이트 제목(브라우저 탭에 뜨는 이름) ② 설명(검색 결과에 나오는 두 줄) ③ 첫 화면 큰 문장을 읽어 와 보여 준다. 사용자가 이걸 하나하나 복사해 올 필요가 없게 하려는 것.
  - 읽어 온 결과를 이렇게 보여 준다: 「사이트에서 이렇게 읽혔어요 · 제목: OO요가 / 설명: 없음 / 첫 화면: Welcome」
  - 일부 사이트 빌더는 로봇이 읽는 걸 막아 둬서 못 읽을 수 있다. 그때: 「사이트가 자동으로 안 읽혀요. 첫 화면 문장만 복사해서 붙여 주세요.」
- 사이트가 여러 개라고 하면: 「5주 동안 실험할 사이트 하나만 골라 주세요」 → 하나만 받는다.

**1-2 · 이름 · 같은 이름 확인 (매번)**
이름을 받는다(채팅):
```
이름을 알려 주세요. (가게 · 브랜드 · 회사 · 내 이름)
```
**Q1-2 [같은 이름]** 같은 이름을 쓰는 다른 곳이 있나요? (다른 지역 가게 · 같은 이름 브랜드 · 동명이인)
| 선택지 | 설명 | 고르면 |
|---|---|---|
| 있어요 | 예: 다른 지역에 같은 이름 병원이 있어요 | Q11 에서 지역이나 하는 일을 이름에 붙이길 추천 (바른피부과 → 해운대 바른피부과) |
| 잘 모르겠어요 | 검색해 본 적 없어요 | 「검색창에 이름만 쳐 보세요. 다른 곳이 먼저 나오면 이름에 지역을 붙이는 게 좋아요」 |
| 없어요 | 이 이름은 우리뿐이에요 | — |
설명 한 줄: 「AI 는 같은 이름이 여러 곳이면 헷갈려서 엉뚱한 곳을 말하기도 해요.」

**1-3 · (선택) 지금 AI 가 나를 뭐라고 하는지 — 운영 중 · 점검 모드일 때만 묻는다**
**Q1-3 [AI 확인]** 지금 AI 가 나를 뭐라고 하는지 먼저 볼래요? (선택 · 5분)
| 선택지 | 설명 |
|---|---|
| 건너뛸게요 (추천) | 재는 건 실험 설계서 기준선에서 해요 |
| 볼래요 | 고친 안을 정하기 전에 지금 상태를 보고 싶어요 |

「볼래요」면 **[물어볼 AI]** 어느 AI 에 물어볼까요? (여러 개 고르기 · 손님이 많이 쓰는 곳으로)
| 선택지 | 설명 |
|---|---|
| ChatGPT | 새 대화 · 로그아웃 상태면 더 좋아요 |
| Perplexity | 시크릿 모드로 |
| 네이버 AI 브리핑 | 네이버 검색창에 그대로 · 국내 손님이면 추천 |
| 구글 AI 개요 · AI 모드 | 구글 검색창에 그대로 |
「직접 입력」으로 Gemini · Copilot 등. 설명 한 줄: 「여기서 고른 곳을 실험 설계서 「테스트할 곳」에 그대로 써요. 시작 전과 5주 뒤에 같은 곳에 물어야 비교돼요.」

그다음(채팅 · 고른 AI 만):
```
아래 질문을 고른 AI 에 그대로 물어봐 주세요.

「(이름)는 뭐 하는 곳이야?」     ← 개인이면 「(이름)은 어떤 사람이야?」

· ChatGPT: 새 대화에서 (로그아웃 상태면 더 좋아요)
· Perplexity: 시크릿 모드에서
· 네이버: 검색창에 그대로 → 맨 위 AI 브리핑 (없으면 「AI 브리핑 없음」)
· 구글: 검색창에 그대로 → 맨 위 AI 개요 (없으면 「AI 개요 없음」)

답을 AI 이름과 함께 붙여 넣어 주세요. 「모르겠다」 · 「없음」도 괜찮아요. 그게 시작점이에요.
예) ChatGPT: 「정보를 찾지 못했어요…」
    네이버: AI 브리핑 없음
```
- AI 마다 판정한다: **모름**(정보 없음 · 브리핑 없음) / **헷갈림**(같은 이름 다른 곳) / **엉뚱함**(다른 일로 소개) / **일부만**(맞지만 빠진 게 많음) / **맞음**
  - 예: 「ChatGPT 는 모르고, 네이버는 AI 브리핑이 안 떠요. 이 한 줄을 심어서 5주 뒤 같은 곳에 다시 물어볼게요.」
  - 하나라도 「헷갈림」이면 이름 표기(Q11)에서 지역이나 하는 일을 붙이는 걸 추천한다(예: 바른피부과 → 해운대 바른피부과).
- **Claude 가 대신 묻지 않는다.** 사용자가 붙여 넣은 답만 쓴다.
- `aiBefore: [{ engine, question, answer, verdict, date }]` (AI 마다 하나) 로 남긴다. 건너뛰면 비워 둔다.

### 2단계 · 무엇을 · 누구에게 (객관식 2개)

**Q4 (브랜드) [업종]** 어떤 업종에 가까워요?
업종 9묶음을 한 번에 4개까지만 보여 줄 수 있으니, 해 온 일을 아직 모르는 상태라 두 번에 나눠 묻는다.
- 1차: 교육 · 자격 / 생활용품 · 식품 / 뷰티 · 패션 / 다른 업종이에요
- 「다른 업종」이면 2차: 가구 · 인테리어 · 시공 / 가전 · IT · B2B / 여행 · 숙박 · 외식 / 의료 · 헬스 · 법률 · 금융 등
- 규제 업종(의료 · 헬스 · 법률 · 금융 · 부동산)이면 이때 한 줄: 「이 업종은 광고 규정이 있어서 표현을 조금 더 조심해서 만들게요.」

**Q4 (개인) [목표]** 나를 알려서 무엇을 얻고 싶어요?
| 선택지 | 설명 |
|---|---|
| 취업 · 이직 | 예: 데이터 분석가로 이직 |
| 일 받기 (프리랜서 · 강사 · 코치) | 예: 1인 디자이너, 요가 강사 |
| 내 글 · 작품 알리기 | 예: 여행 작가, 영상 크리에이터 |
| 창업 준비 | 예: 곧 열 공방을 미리 알리기 |

**Q5 [대상]** 누가 내 사이트를 봤으면 해요?
업종 · 목표에 맞는 대상 3개를 Claude 가 만들어 선택지로(references/industries.md 의 예시에서 출발).
- 예 (반려견 간식): 알레르기 있는 강아지 보호자 / 처음 간식 고르는 초보 보호자 / 선물용 간식 찾는 사람
- 예 (요가 강사): 허리 뻐근한 직장인 / 처음 요가하는 사람 / 임신 · 출산 뒤 운동하려는 사람

### 3단계 · 해 온 일 · 자주 받는 질문 (채팅)
```
두 가지만 짧게 적어 주세요. 한 줄씩이면 충분해요.

① 지금까지 해 온 일 (브랜드면 무엇을 · 어떻게 만드는지)
   예) 원재료 5가지 이하로 강아지 간식을 만들어요. 재료표를 다 공개해요. 2년째 해요.

② 고객이나 주변에서 자주 받는 질문 3개
   예) 닭 알레르기 있어도 먹을 수 있어요? / 처음엔 얼마나 줘요? / 유통기한은요?
```
- ①이 너무 짧으면(한 단어) 한 번만 되묻는다: 「어떻게 하는지 한 가지만 더요. 예: 재료를 줄인다, 소수로만 수업한다」
- ②가 안 떠오른다고 하면: 「그럼 손님이 사기 전에 망설이는 이유 하나만요」로 바꿔 묻는다.
- ②는 핵심 질문 · 측정 질문의 씨앗이 된다.

### 4단계 · 검색하는 말 · 알릴 범위 · 바라는 행동 (객관식 3개)

**Q6 [검색하는 말]** 손님이 이 일을 검색할 때 뭐라고 칠까요?
- 해 온 일 · 업종으로 **Claude 가 검색하는 말 3개를 만들어** 선택지로.
- 예: 강아지 수제 간식 / 반려견 수제 간식 / 저알러지 강아지 간식
- 설명: 「내가 부르는 이름 말고, 손님이 검색창에 치는 말이에요. 사이트 제목 앞부분에 들어가요.」

**Q7 [알릴 범위]** 어디까지 알려지면 돼요?
| 선택지 | 설명 | 고르면 |
|---|---|---|
| 우리 동네 · 지역 | 예: 망원동, 부산 해운대 | 채팅으로 지역 이름 |
| 온라인 전국 | 지역 상관없이 | — |
| 해외도 | 다른 나라 말로도 | 4-1 로 |

**Q8 [바라는 행동]** 사이트를 본 사람이 무엇을 했으면 해요?
| 선택지 | 설명 |
|---|---|
| 문의 · 상담 | 예: 수업 문의, 견적 요청 |
| 구매 · 예약 | 예: 스토어로 가서 주문 |
| 팔로우 · 구독 | 예: 인스타 팔로우, 뉴스레터 |
| 읽고 기억해 주면 돼요 | 지금은 알리는 게 먼저 |

### 4-1 · 해외면: 나라 · 언어 (객관식 1개)

**Q9 [언어]** 어느 나라 사람에게 알리고 싶어요? (여러 개 고르기)
| 선택지 | 설명 |
|---|---|
| 영어권 | 예: 미국 · 영국 · 싱가포르 |
| 일본 | 일본어 |
| 중국어권 | 예: 중국 · 대만 (간체 · 번체는 다음에 물어요) |
| 유럽 | 예: 독일 · 프랑스 · 스페인 → 채팅으로 나라 받기 |

- 고른 언어마다 **번역이 아니라 그 나라에서 검색하는 말로 다시** 만든다: 한 줄 · 사이트 제목 · 설명 · 소개문 짧게.
- 그 나라 손님이 검색할 말을 Claude 가 2~3개 제안하고 고르게 한다(Q6 과 같은 방식, 언어마다 한 번).
- 리포트 · 파일에 「번역은 초안이에요. 그 나라 말을 쓰는 분께 한 번 보여 주세요」 한 줄.
- 글자 수 기준은 언어마다 다르게(9장 문구 기준).

### 5단계 · 증거 · 이름 표기

**Q10 [증거]** 말할 수 있는 증거가 있어요? (여러 개 고르기)
| 선택지 | 설명 |
|---|---|
| 해 온 기간 · 횟수 | 예: 2년째, 수업 300회 |
| 손님 수 · 판매 수 · 후기 | 예: 후기 120개 |
| 자격 · 수상 · 기관 · 언론 소개 | 예: 요가 지도자 자격 |
| 직접 만든 자료 · 공개한 기준 | 예: 원재료표 공개, 가격표 공개 |

업종 · 목표에 따라 예시를 바꾼다(references/evidence.md). 고른 것마다 채팅:
```
고른 것의 숫자나 이름을 적어 주세요.
정확하지 않으면 「대략」이라고 써 주세요. 대략인 숫자는 문구에 넣지 않아요.

예) 2년 / 후기 대략 100개 / 원재료표 전 제품 공개
```
- 아무것도 없다고 하면: 「괜찮아요. 「직접 해 본 것」이 증거가 돼요. 위키에서 같이 모아요.」

**Q11 [이름]** 이름은 어떻게 쓸까요?
| 선택지 | 예 |
|---|---|
| 한글만 | 온새 펫베이커리 |
| 영문만 | ONSAE Pet Bakery |
| 둘 다 | 온새 펫베이커리 (ONSAE) |
설명: 「사이트 · SNS 어디서나 똑같이 써야 같은 곳으로 알아봐요.」 해외를 골랐으면 「둘 다」를 추천으로 맨 위에.

### 6단계 · 채널

**Q12 [쓰는 채널]** 지금 쓰는 채널을 모두 골라 주세요. (여러 개 고르기 · 선택지는 4개까지라 묶어서)
| 선택지 | 설명 |
|---|---|
| 인스타그램 · 스레드 | |
| 유튜브 | |
| 블로그 | 네이버 블로그 · 티스토리 등 |
| 링크드인 | |
「직접 입력」으로 스토어 · 쇼핑몰 등을 받는다. 고른 것의 주소를 채팅으로(없으면 「아직 없음」):
```
쓰는 채널 주소를 붙여 주세요. 지금 이름 · 소개는 제가 읽어 올게요.
예) instagram.com/내아이디 · blog.naver.com/내아이디 · youtube.com/@내채널
```
**지금 프로필 읽어 오기** (references/channels.md 「읽어 오기」 표):
- 스레드 · 유튜브 · 네이버 블로그(모바일 주소로) · 링크드인 회사 페이지는 주소로 읽힌다 → 「인스타는 소개가 안 읽혀요」처럼 못 읽은 곳만 따로 받는다.
- 인스타그램은 이름만 읽히고 소개(바이오)는 안 읽힌다. 링크드인 개인 프로필은 로그인 때문에 막힐 수 있다.
- 못 읽은 곳은: 「이 채널은 자동으로 안 읽혀요. 프로필 소개를 복사해 붙이거나, 프로필 화면 캡처를 이 창에 끌어다 놓아 주세요.」 (캡처면 이미지를 읽어 이름 · 소개를 옮긴다)
- 읽은 값은 「지금 이렇게 되어 있어요」로 짧게 보여 주고 `channels[].current = { name, intro, readFrom }` 에 남긴다.

**Q13 [핵심 채널]** 이 중 사이트와 같이 키울 핵심 채널 1~2개는?
- Q12 에서 고른 것 + 「추천해 주세요」.
- 추천 기준: 대상이 실제로 정보를 찾는 곳. 예) 동네 가게 → 인스타 · 블로그 / 이직 → 링크드인 / 강의 · 노하우 → 유튜브 · 블로그.
- 설명: 「다 하지 말고 하나만 제대로 해도 돼요. 나머지는 이름 · 링크만 맞춰 둬요.」
- 채널이 하나도 없으면 대상에 맞는 2개를 추천하고, 리포트에 그 채널의 가입 안내를 넣는다(대신 만들지는 않음).

**가입 안내 대상 채널 (5개)**: 인스타그램(프로페셔널 계정) · 스레드(인스타로 생성) · 링크드인(개인 프로필 / 회사 페이지) · 유튜브(채널명 = 핸들) · 블로그. 채널마다 가입 링크 · 3단계 · 프로필 체크리스트(이름 · 아이디 · 소개 · 사진 · 링크) · 주의 한 줄(references/channels.md).

### 7단계 · 한 줄 컨셉 고르기

**새로 만들기 모드** — 채팅에 표를 먼저 출력:

| | 한 줄 컨셉 | 누구에게 | 무엇을 | 어떻게(다른 점) |
|---|---|---|---|---|
| A | … | … | … | … |
| B | … | … | … | … |
| C | … | … | … | … |

세 후보는 서로 다르게: A = 대상 중심, B = 다른 점(증거) 중심, C = 다른 대상 · 다른 상황.

**Q14 [한 줄]** 어느 쪽이 가까워요?
- A / B / C — 각 선택지 preview 에 그 한 줄 + 검색 결과 미리보기(제목 · 설명 두 줄)
- 「직접 입력」 = 섞고 싶어요 → 채팅으로 받아 다시 표 → 다시 묻기

**점검 모드** — 진단 표를 먼저:

| 지금 문구 | 누구에게 | 무엇을 | 어떻게 | 검색하는 말 | 과장 · 근거 없음 |
|---|---|---|---|---|---|
| 「…」 | 있음 / 빠짐 | … | … | 앞에 있음 / 없음 | 있으면 짚기 |

→ 원래 ↔ 고친 안 1~2개를 나란히. 세 칸 중 둘 이상 빠졌으면 「아예 바꿀 안」 2개를 더.
→ **Q14 [한 줄]** 지금 문구 그대로 / 고친 안 1 / 고친 안 2 / 아예 바꿀 안

### 8단계 · 측정 질문 3개 고르기
7장 「측정 질문 만드는 법」대로 후보 6개를 표로 보여 주고:

후보 6개 = 층마다 2개 · 3층 넓은 말(검색어) / 2층 손님 상황(문장) / 1층 내 다른 점(문장) (references/measure.md).

**Q15 [측정 질문]** 5주 동안 AI 에게 물어볼 3개를 골라 주세요.
- 선택지: 추천 묶음(층마다 하나) / 다른 조합 / 직접 고를게요(채팅으로 번호)
- 설명: 「좁은 1층부터 잡히고 위로 넓혀 가요. 그래서 층마다 하나씩 재요.」
- 3개가 아니면: 「3개로 맞춰 주세요. 모두 같은 수로 재야 나중에 합칠 수 있어요.」
- 해외를 골랐으면 이어서 **Q15b [해외 질문]** 「그 나라 말로 묻는 질문도 하나 따로 만들까요? (기준선 3개와는 따로 재요)」 만들어요 / 괜찮아요 → 만들면 그 나라 말 2층 문장 하나를 `measureExtra` 에.
- 한 층에서 둘을 고르면: 「층마다 하나씩이에요. 빠진 층에서 하나를 골라 주세요.」

### 9단계 · 나머지 확인
한 줄 · 측정 질문이 정해지면 아래를 **채팅에 표로 한 번에** 보여 주고:

1. 사이트 제목 · 2. 설명 · 3. 소개문 짧게 · 4. 소개문 길게 · 5. 채널별 프로필(이름 · 아이디 · 소개 · 링크, 다르면 「고칠 것」) · 6. 핵심 질문 후보 5개 · 7. 근거 자산 · 8. 채널 연결 계획 · (해외면) 9. 언어별 한 줄 · 제목 · 설명 · 소개문

**Q16 [확인]** 이대로 갈까요?
- 이대로 좋아요 / 고칠 게 있어요(채팅) / 처음 한 줄부터 다시
- 고치면 고친 표 전체를 다시 보여 주고 다시 묻는다.

### 10단계 · 저장 · 리포트 · 마무리
파일 저장 → 리포트 열기 → 마무리 말(그대로):
```
컨셉 리포트를 열었어요. 이제 이렇게 하세요.
1. 리포트의 「채널 맞추기」 표대로 SNS 프로필을 고쳐요 (이름 · 소개 · 링크)
2. 「측정 질문 3개」를 실험 설계서의 기준선 칸에 옮겨 적고, 지금 한 번 물어봐요
   5주 뒤엔 처음 물어본 「(이름)는 뭐 하는 곳이야?」도 다시 물어봐요
3. 다음은 사이트예요 → 이 창에 「사이트 설계해 줘」
   (이미 사이트가 있으면 「위키 만들어 줘」)
```

## 사이트 읽어 오기 (1-1)

점검 모드에서 사용자가 사이트 주소를 주면, Claude 가 그 페이지를 열어 **지금 걸려 있는 글자**를 직접 읽는 것.

| 읽는 것 | 어디에 보이는 것 | 왜 |
|---|---|---|
| 사이트 제목 | 브라우저 탭 · 검색 결과 파란 제목 | 검색하는 말이 앞에 있는지 |
| 설명 | 검색 결과 제목 아래 두 줄 | 비어 있거나 너무 긴지 |
| 첫 화면 큰 문장 | 사이트 열면 처음 보이는 문장 | 누구에게 · 무엇을이 보이는지 |
| (있으면) SNS 소개 | 인스타 · 블로그 프로필 | 사이트와 같은 말인지 |

- 사용자가 복사해 오지 않아도 되고, 「검색엔진이 실제로 보는 글자」를 그대로 볼 수 있다는 게 장점.
- 일부 빌더는 로봇을 막아서 못 읽을 수 있다 → 「첫 화면 문장만 복사해 붙여 주세요」로 바꾼다.
- 인스타처럼 로그인해야 보이는 곳은 읽지 않고 붙여 넣기로 받는다.
